# Two players play a game to a win

## Start a two-player game
Click "2 Players".

## Play a winning top row for the first player
Click the top-left square, then the middle-left square, then the top-middle square, then the centre square, then the top-right square.

## See the win
Verify the page shows "Winner: Player".
Verify the score for O shows "1 / 5".
