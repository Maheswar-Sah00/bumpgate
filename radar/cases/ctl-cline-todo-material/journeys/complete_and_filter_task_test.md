# Mark a task as done and filter the list by Active and Completed

## Add a task
Type "Pay electricity bill" into the "Title" field and click the "Add Task" button.
Verify the task "Pay electricity bill" appears in the list and the text "1 of 1 task active" is shown.

## Mark the task as done
Tick the checkbox next to "Pay electricity bill".
Verify the text "0 of 1 task active" is shown and a "Clear completed" button appears.

## Show only active tasks
Click the "Active" filter button.
Verify the text "No active tasks – nice work!" is shown and "Pay electricity bill" is not in the list.

## Show only completed tasks
Click the "Completed" filter button.
Verify the task "Pay electricity bill" is shown in the list.
