# Clear a loaded session with "LOAD ANOTHER" so no old lap data is left on screen

## Load the demo session
Click the "TRY DEMO" button and wait until the heading "Lap time report" and the driver "Demo Driver 03" are shown.

## Start over
Click the "LOAD ANOTHER" button.

## Check that the old report is gone
Verify the panel heading reads "Load a session" and the text "Drop your session file here" is visible again.
Verify the "TRY DEMO" button is shown again, and that the text "Lap time report", "Demo Driver 03" and "1:43.493" no longer appear anywhere on the page.
