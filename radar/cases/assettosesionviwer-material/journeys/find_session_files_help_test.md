# Show where to find session files before any file is loaded

## Check the upload options
On the home page, check that the "TRY DEMO" button, the "DOWNLOAD JSON" link and the text "JSON SESSION FILES · PROCESSED LOCALLY" are visible, and that no lap time table is shown yet.

## Open the help section
Click the "Where can I find my session files?" toggle below the drop area.

## Check the folder path
Verify the text "In File Explorer, paste this path into the address bar:" is shown, followed by the path "%LOCALAPPDATA%\AcTools Content Manager\Progress\Sessions".
