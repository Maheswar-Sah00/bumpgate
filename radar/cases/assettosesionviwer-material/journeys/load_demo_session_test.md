# Load the demo session and see the lap time report

## Check the empty state
On the home page, check that the panel heading reads "Load a session" and that the area saying "Drop your session file here" is visible.

## Load the demo session
Click the "TRY DEMO" button and wait for the report to appear.
Verify the panel heading now reads "Lap time report".

## Check the session summary
Verify the summary shows FILE "demo-session.json", DRIVERS "3" and LAPS "9".

## Check the lap time table
Verify the table has the column headings "DRIVER / CAR", "LAP 1", "LAP 2" and "LAP 3".
Verify the row for "Demo Driver 01" shows the lap times "1:42.245", "1:41.754" and "1:41.336", and that rows for "Demo Driver 02" and "Demo Driver 03" are also shown.
