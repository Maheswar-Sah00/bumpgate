# A player whose bot crashed looks up the meaning of error code E017

## Open the API reference
In the top menu bar, click the "Docs" link.
Verify the page shows the heading "Bot Development".

## Follow the link to the error codes
Scroll down to the "Code guard rails" section under "Coding Tips" and click the "error code reference" link.
Verify the page shows the heading "Error codes" and explains that a fatal code means the bot is killed and removed from the arena.

## Find the most common load error
Scroll down to the "E017" entry.
Verify its description starts with the text "Bot script failed to load — fatal."
