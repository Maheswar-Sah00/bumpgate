# A newcomer opens the Learn to Code course and moves from lesson 1 to lesson 2

## Open the course from the top bar
In the dark menu bar at the top of the page, click the "Learn" link.
Verify the page shows the heading "Learn to Code with Robots" and a list of lessons that includes "Hello, bot!".

## Start lesson 1
In the lesson list, click the "Hello, bot!" link.
Verify the page shows the heading "Lesson 1: Hello, bot!" and the example code line "bot.setName('Rusty');".

## Go to the next lesson
Scroll to the bottom of the lesson and click the link "Do something every moment →".
Verify the page shows the heading "Lesson 2: Do something every moment".

## Return to the course index
Scroll to the bottom of lesson 2 and, in the footer line that also links "← Hello, bot!" and "Move! →", click the "Index" link.
Verify the page again shows the heading "Learn to Code with Robots".
