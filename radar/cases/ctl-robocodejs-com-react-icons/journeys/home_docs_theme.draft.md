# A visitor reads the home page, opens the API reference, jumps to a section and switches the colour theme

## Read the home page
Look at the left half of the page, below the top menu bar.
Verify it shows the heading "RobocodeJs", the text "Welcome to the arena!" and a "Getting started" section.

## Open the API reference
In the top menu bar, click the "Docs" link.
Verify the page shows the heading "Bot Development" and a bulleted list of sections that includes "Bot radar".

## Jump to a section
In that bulleted list, click the "Bot radar" link.
Verify the "Radar" section with its "Scanning" subheading is now visible on screen.

## Switch the colour theme
At the right end of the top menu bar, next to the "How do I..." search box, hover over the small sun or moon icon button and note its tooltip, which reads either "Switch to night mode" or "Switch to light mode". Click the button once, then hover over it again.
Verify the tooltip now shows the other text: "Switch to light mode" if it was "Switch to night mode" before, or "Switch to night mode" if it was "Switch to light mode" before, and the "Bot Development" heading is still shown.
