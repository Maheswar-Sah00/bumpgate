# Move between the main pages from the sidebar menu

## Open the Reports page
In the sidebar menu, click "Reports".
Verify the page heading "Analysis Reports" and the text "Comprehensive archive of agent findings and alerts" are visible.

## Open the Prompts page
In the sidebar menu, click "Prompts".
Verify the page heading "Prompt Manager" is visible.

## Open the Agent Monitor page
In the sidebar menu, click "Agent Monitor".
Verify the text "Event-driven health analysis agent" is visible.

## Return to the Dashboard
In the sidebar menu, click "Dashboard".
Verify the subtitle "Real-time live health management" is visible and the "Analysis Reports" heading is no longer shown.
