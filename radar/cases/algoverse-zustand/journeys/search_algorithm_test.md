# Search for Dijkstra from the home page and run it

## Open the search
On the home page, click the "Search an algorithm" button.
Verify a search box with the placeholder starting "An algorithm, or a command" is shown.

## Search for Dijkstra
Type "dijkstra" into the search box.
Verify a result named "Dijkstra" with the description "Greedy relaxation with a priority queue." is listed under "algorithms".

## Open the result
Click the "Dijkstra" result.
If a "Welcome to AlgoVerse" guided tour appears, close it with its close (X) button or by pressing Escape.
Verify the heading "Dijkstra" is shown next to the category "Graphs".

## Run it to the end
In the playback controls, click the "Jump to end" button (the jump to last step control), or press the End key.
Verify the status text "complete" is shown below the visualiser.
