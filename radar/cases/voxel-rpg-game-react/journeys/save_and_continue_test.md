# A player saves their game from the pause menu and can continue it after reloading

## Start a game
Click the "Start Game" button on the title screen (if it is labelled "New Game" instead, click that).
Wait a few seconds until the game screen shows "Level 1" and "Day 1".

## Open the pause menu
Press the F10 key.
Verify a menu titled "Paused" appears with the buttons "Resume", "Save Game" and "Load Game".

## Save the game
Click the "Save Game" button.
Verify the message "Game saved!" appears in the pause menu.

## Reload and find the save
Reload the page and wait for the title screen to load.
Verify a "Continue" button showing "Lv 1" is visible above a "New Game" button.
