# A new player starts a game from the title screen and opens the build catalog

## Check the title screen
Wait for the title screen to load over the 3D world.
Verify the tagline "Carve the land. Raise a settlement. Close the rifts." and a "Start Game" button are visible.

## Start a new game
Click the "Start Game" button (if it is labelled "New Game" instead, click that).
Verify the title screen goes away and the game screen shows the player status with the text "Level 1" and the clock with the text "Day 1".

## Open the build catalog
Click the "Build" button in the bottom-left action bar.
Verify a panel titled "Build" opens with the tabs "Blocks" and "Buildings".

## Browse the buildings
Click the "Buildings" tab.
Verify the building card "Wooden Shelter" is visible in the list.
